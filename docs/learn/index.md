# Learn fckt

Each lesson explains one part of the language, then gives you a small task to finish in the
editor. Check runs your code against a test in your browser and tells you what, if anything, is
still wrong. If you get stuck, there are hints, and after a couple of tries the solution.

Your progress is kept in this browser, and finished lessons are ticked in the sidebar.

1. [Values](/learn/values): names, and putting values in strings.
2. [Functions](/learn/functions): parameters, blocks, and calling one function from another.
3. [Lists and lambdas](/learn/lists): `map`, `filter` and `fold`.
4. [Records](/learn/records): types with fields, and copying with changes.
