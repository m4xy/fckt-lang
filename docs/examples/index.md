# Examples

These pages build whole programs, from an empty folder to something you can run. Each one shows
the full code, then walks through the parts that are worth a closer look.

- [A command-line tool](/examples/grep): a small grep, built from a regular expression library and a
  command-line parser, with tests.
- [A web service](/examples/url-shortener): a URL shortener with an HTTP API and a database.
- [Counting words](/examples/word-count): the most common words in a set of files, using only the
  standard library.
- [A todo list](/examples/todo): a to-do list kept in a text file, using only the standard library.
